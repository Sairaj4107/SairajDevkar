// 04 — Projects

What I've Built

// 001
Industry Sponsored
IoT Pressure Data Logger with Cloud Reporting

Designed and developed a field-deployable IoT data logger that acquires pressure readings from a 4–20 mA current-loop sensor, converts raw current variation to calibrated pressure values, and transmits real-time data to AWS IoT Cloud via a 4G GSM module. The system fetches live data to a mobile app and auto-generates daily PDF reports delivered to Gmail — enabling remote condition monitoring without manual intervention. Powered by a 12.6V lithium-ion battery pack for extended field backup. Architected for multi-sensor expansion for future scalability.

Embedded C4G GSM ModuleAWS IoT Cloud4–20mA Current LoopUARTADCLi-ion Battery
Client — Aquaindica Techno Solutions Pvt. Ltd.
// 002
Industry Sponsored
CAN-Based Elevator RGB Ambient Lighting System

Built a CAN bus-controlled RGB ambient lighting solution for elevator car tops, delivering dynamic lighting effects based on elevator state — directional motion (up/down), door events (open/close), and idle power-down mode. The system receives real-time elevator state signals over CAN and drives LED effects accordingly. A passenger-facing color-selection slider on the COP (Car Operating Panel) allows custom color preferences, enabling a fully interactive ambient lighting experience. Designed for low-power operation with automatic standby mode when no calls are registered.
